# PDF Master

PDF Master is an offline-first Windows PDF toolkit built with Python 3.12 and PySide6. Milestone 1 delivers the production-oriented application foundation, responsive UI shell, dashboard, developer branding, local configuration, and privacy-conscious logging.

## Run locally

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app/main.py
```

Run tests with `python -m pytest`.

## Privacy

PDF Master processes documents locally. It contains no telemetry or analytics and does not upload document contents, filenames, or activity.
